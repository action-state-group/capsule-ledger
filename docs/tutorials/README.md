# Tutorials

Short, copy-paste walkthroughs against a real, deterministic ledger. Start at the top and go in order.

1. [Your first ledger](01-your-first-ledger.md) — generate a real ledger with the deterministic simulator, then read it with `log`/`show`/`verify`. ~5 minutes.
2. [Reading what happened](02-reading-what-happened.md) — filters, `show`, `diff`, `blame`, and `bisect`, on the same fixture.
3. [Folds and caps](03-folds-and-caps.md) — the guard checks, the fold catalog, a real caps escalation walked end to end, and the manifest that pins which policy was live.
4. [Bundle and verify](04-bundle-and-verify.md) — hand a stranger a self-contained slice of your ledger and let them verify it for free.

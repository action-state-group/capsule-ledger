# Governance
This repository is **company-led open source** (Apache-2.0, DCO), maintained by its
original authors. It implements the Agent Action Capsule format, whose specification has
open change control at the IETF and whose canonical project governance — including which
repositories are foundation-bound — is published at
<https://agentactioncapsule.org/docs/governance.html>. **This repository is not part of
the donation set** and has no special status with respect to the specification.
